<objective>
Run the dental pack on the real local model, tune the pack within a fixed budget, and write the dental baseline only if the gates are met (EVAL-03; D-10, D-14).

Gate: no category under 90% (at 3-5 scenarios per category this means every scenario passes) AND emergency escalation recall 100%, on local llama3.1:8b. Bounded tuning: at most 3 iterations; edit pack FAQ/messages/qualification synonyms/escalation regex only; NEVER weaken, delete or reword scenarios, NEVER change shared code to pass. If unreachable after 3 iterations: record the real per-category numbers, flag to the user, do not fudge, do not write a dental baseline.

Rules: never run pytest and an eval concurrently (run `make g-test` only when no eval is running, strictly before or after); evals are local-only, run as BACKGROUND commands, using exactly `docker compose -p roofdesk-global -f docker-compose.yml -f docker-compose.override.yml -f docker-compose.global.yml exec -T -e LLM_TIMEOUT_S=300 -e GIT_SHA=$(git rev-parse --short HEAD) api python -m evals.runner --pack bright-smile-dental ...` after warming llama3.1:8b; hosted provider keys unset for the run; never touch the live DB or push; commits `<type>: <description>`, no attribution/Co-Authored-By; never edit evals/baselines/v1-roofing.json.
</objective>
