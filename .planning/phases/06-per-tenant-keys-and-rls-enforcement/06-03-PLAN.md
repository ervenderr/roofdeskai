## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> X-API-Key | untrusted credential resolves to a tenant |
| tenant key -> admin endpoints | must not cross into super-admin scope |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-08 | Spoofing | key brute force / guess | mitigate | 256-bit random, prefix and length precheck, generic 401 |
| T-06-09 | Information disclosure | key theft from DB | mitigate | sha256 hash only, plaintext returned once, list endpoint omits hash |
| T-06-10 | Spoofing | invalid key falling through to demo or admin path | mitigate | present-but-invalid X-API-Key is always 401, tested |
| T-06-11 | Elevation | tenant key reaching /admin/tenants or key endpoints | mitigate | those routes depend on require_admin only, tested with a tenant key |
| T-06-12 | Spoofing | X-Tenant-Id honoured for tenant keys | mitigate | header read only after a valid admin key |
| T-06-SC | Tampering | package installs | accept | none installed |
</threat_model>
