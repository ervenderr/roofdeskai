## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API payload -> HTML | customer email text and review text are untrusted |
| URL query -> page | `?decided=` is attacker-controllable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-07 | Tampering (XSS) | quotes/reviews pages | mitigate | render customer and model text as JSX text only; grep gate forbids dangerouslySetInnerHTML |
| T-12-08 | Tampering | `?decided=` | mitigate | decidedMessage maps only known keys to fixed strings; the raw value is never rendered |
| T-12-09 | Info disclosure | PII in URLs/static build | mitigate | no customer text in hrefs or query strings; static export renders no drafts |
| T-12-10 | Elevation | direct URL by operator or module-less tenant | mitigate | requireTenantModule -> notFound(); nav hides the link (plan 01) |
| T-12-11 | Repudiation | misleading "sent" impression | mitigate | buttons carry the "Nothing is sent or posted" line and decided messages repeat it |
</threat_model>
